# Foundly Landing

Лендинг исследовательского пилота Foundly объединяет оффер для трёх стартовых сценариев, пошаговую intake-форму и first-touch UTM-атрибуцию. Сейчас доступна бесплатная диагностика и предварительная заявка; платный запуск не открыт.

## Стек

- Next.js 16, App Router
- React 19, JavaScript
- Глобальный адаптивный CSS без UI-библиотеки
- Google Sheets и бесплатный Google Apps Script для заявок
- Vitest и ESLint

## Структура

- `app/` — страницы, metadata, robots и sitemap
- `components/sections/` — независимые секции лендинга
- `components/forms/` — пошаговая форма и условные поля
- `lib/content.js` — тексты, сценарии, форматы и ссылки
- `lib/analytics/` — UTM и абстракция событий
- `lib/leads/` — поля, нормализация, валидация и отправка в Google Sheets
- `integrations/google-sheets/` — шаблон таблицы, Apps Script и инструкция подключения
- `tests/` — валидация, роли, UTM и отправка формы
- `public/` — оптимизированно отдаваемый логотип Foundly

## Установка и запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

Откройте `http://localhost:3000`.

## Переменные окружения

| Переменная | Назначение | Обязательность |
| --- | --- | --- |
| `NEXT_PUBLIC_GOOGLE_SHEETS_WEBHOOK_URL` | URL deployment Google Apps Script | Обязательна для формы |
| `NEXT_PUBLIC_SITE_URL` | Канонический адрес для metadata и sitemap | Обязательна в production |
| `PRIVACY_CONTACT_EMAIL` | Адрес для отзыва согласия и удаления данных | Обязательна до production-сбора |
| `DATA_RETENTION_DAYS` | Настраиваемый срок хранения | По умолчанию 90 |

`.env` и локальные варианты исключены из Git. URL Apps Script является публичной точкой приёма формы, а не секретом.

## Архитектура формы

Форма состоит из трёх шагов: роль, общие контакты, контекст роли. Состояние хранится в родительском React-компоненте и не теряется при переходах. CTA может заранее выбрать роль, сценарий и источник клика.

Общие поля: имя, email или телефон, город, способ связи, сообщение и согласие. Для школьника или студента запрашиваются возрастная группа, стадия, направление, цель, дедлайн и сценарий. У несовершеннолетнего обязательны имя и контакт родителя и подтверждение его информирования. Для родителя запрашиваются возрастная группа ребёнка, стадия, цель, дедлайн, сложность и сценарий. Для ментора — экспертиза, опыт, профессиональная ссылка, типы проектов, доступность и мотивация.

Клиентская валидация отвечает за UX и условные поля. Google Apps Script повторно проверяет обязательные поля и honeypot перед добавлением строки. Полные персональные данные не выводятся в браузерные или серверные логи проекта.

## Доставка заявок

Форма отправляет JSON напрямую в Google Apps Script через `NEXT_PUBLIC_GOOGLE_SHEETS_WEBHOOK_URL`. Отдельный backend, база данных и платный сервер не нужны. Без URL форма явно сообщает, что Google Sheets ещё не подключена.

Подключение:

1. Импортировать `integrations/google-sheets/Foundly Leads.xlsx` в Google Sheets.
2. Открыть **Расширения → Apps Script**.
3. Вставить `integrations/google-sheets/Code.gs`.
4. Развернуть скрипт как Web app с доступом по ссылке.
5. Добавить URL deployment в `.env.local`.

Подробности находятся в `integrations/google-sheets/SETUP.md`. Доступ к самой таблице должен быть только у назначенных членов команды Foundly.

## UTM и события

При первом входе в `sessionStorage` сохраняются `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`, referrer и landing path. Повторные переходы в той же сессии не перезаписывают first-touch данные. В заявку также добавляются выбранный CTA и сценарий.

Примеры:

- Instagram: `/?utm_source=instagram&utm_medium=social&utm_campaign=foundly_launch`
- Threads: `/?utm_source=threads&utm_medium=social&utm_campaign=foundly_launch`

События `intro_completed`, `cta_clicked`, `scenario_selected`, `form_started`, `form_step_completed`, `form_submitted`, `form_error` отправляются через браузерное событие `foundly:analytics`. Это адаптер без стороннего SDK; production-провайдер можно подключить одним слушателем.

## Незаполненные данные

В `lib/content.js` намеренно оставлены пустыми:

- контакт Foundly
- реквизиты ответственного лица/оператора данных

Instagram и Threads настроены на официальные профили `foundly.kz`. В `.env.local` необходимо заполнить production URL, email для privacy-запросов и URL Google Apps Script. Пустой контакт отображается как «скоро» и не создаёт ложного перехода.

## Git workflow

Начальный scaffold зафиксирован отдельным коммитом в `main`. Реализация ведётся в `feature/pro-49-pro-69-landing-intake`. Merge и push выполняются только после отдельного решения.

## Ограничения пилота

- Диагностика бесплатная, заявки рассматриваются вручную.
- Цены 35 000 ₸ и 55 000 ₸ показаны только как планируемые ориентиры.
- Оплата, платёжные кнопки и автоматический подбор не подключены.
- Победа, поступление и конкретный коммерческий результат не гарантируются.
- Проект не заявляет государственную сертификацию или юридическое одобрение.
- Публикация имени, проекта, фото, видео или голоса требует отдельного согласия.
- Платный запуск блокируют выбор законного исполнителя, инфраструктуры хранения данных в Казахстане, заполнение реквизитов, политика возвратов и договоры с менторами.
